# Air

Небольшой 3-страничный сайт (главная, отзывы, услуги). Учебный проект: в настоящий момент на доработке - переход от css на scss, со статичной верстки на адаптивную, изменение структуры папок, перевод иконок на svg, добавление интерактива на JS, корректировка нейминга по БЭМ, отправки формы.

Демо: https://rudanastasia.github.io/air/

## Технологии

- HTML5, SCSS (компилируется в `css/main.css` через Prepros)
- ESLint + Prettier — линтинг и форматирование

## Структура проекта

```
├── index.html          # разметка главной страницы
├── services.html       # разметка страницы услуг
├── reviews.html        # разметка страницы с отзывами
├── css/                # SCSS + скомпилированный main.css
├── img/                # изображения и иконки
```

## Установка

```bash
npm install
```

## Скрипты

| Команда                | Назначение                              |
| ---------------------- | --------------------------------------- |
| `npm run lint`         | проверить JS на ошибки ESLint           |
| `npm run lint:fix`     | автоматически исправить то, что чинится |
| `npm run format`       | отформатировать проект Prettier         |
| `npm run format:check` | проверить форматирование без изменений  |
