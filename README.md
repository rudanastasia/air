# Air

Небольшой 3-страничный сайт (приветственная страница, главная, отзывы, услуги).

Демо: https://rudanastasia.github.io/air/welcome.html

## Технологии

- HTML5, SCSS, JS (компилируется в `css/main.css` через Prepros)
- ESLint + Prettier — линтинг и форматирование

## Структура проекта

```
├── index.html          # разметка приветственной страницы
├── index.html          # разметка главной страницы
├── services.html       # разметка страницы услуг
├── reviews.html        # разметка страницы с отзывами
├── script.js           # скрипты
├── css/                # SCSS + скомпилированный main.css
├── img/                # изображения и иконки
```

## Установка

```bash
npm install
```

## Скрипты

| Команда                | Назначение                              |
| ---------------------- | --------------------------------------- |
| `npm run lint`         | проверить JS на ошибки ESLint           |
| `npm run lint:fix`     | автоматически исправить то, что чинится |
| `npm run format`       | отформатировать проект Prettier         |
| `npm run format:check` | проверить форматирование без изменений  |
